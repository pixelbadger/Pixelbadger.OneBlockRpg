One Block CRPG: Specification

Implementation baseline for Pixelbadger.OneBlockRpg · Draft 0.1 · 2026-09-30

Status: draft for discussion. This document captures the researched concept and a proposed architecture. Anything marked open needs a decision before implementation. The complete list is in §6.

What we are building

A TypeScript text adventure engine built around Warren Spector's one city block RPG ideal. The game world is small and bounded: a single city block. Everything inside it is simulated in depth, including buildings, rooms, objects, utilities and residents with routines, relationships, memories and goals. LLMs supply what has historically made the idea impractical: characters who can talk about anything and plotlines that grow out of the simulation instead of being scripted. Claude, accessed through a Claude subscription, is the default model backend. The model layer is a pluggable provider interface.

The one-sentence architecture

A deterministic simulation owns the truth. The LLM interprets, voices and suggests. The simulation validates and applies.
