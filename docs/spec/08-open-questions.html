#QuestionDecision
Q32Should rooms have space, and should combat use it?Yes. P3 was rewritten: rooms are drawn tile maps in the manner of Ultima V, positions are ground, and combat is fought on the tiles (range, reach, line of sight, movement in AP). Geometry stays coarse: walkable, adjacent, visible, distance (§4.10, §5.6).
Q33Where do room maps come from?Authored in the payload, one per room, required. No generated fallback (§7.10).
Q34Payload and save compatibility for mapsSchema 2.0 requires maps. Saves from before maps load: things that have no tile yet are placed on their authored tile, or the nearest free one.
Q35How does the player move in a tiled frontend?One step action per tile, in eight directions; every other action walks to its target first (§4.10). The readline CLI keeps typed commands. The TUI is keys only, in the Ultima V manner.
Q36What does a step cost?10 game seconds outside combat, 1 AP in it.

Q3Where the block comes fromAuthored as a game payload. A coding agent builds it from the user's story brief (§7).

Q5Player goal and plotThe user supplies plot, characters, tensions, trigger points and set pieces (§7.2).
Q6Edge of the blockAlways impassable. No payload can declare an exit off the block (P1).
Q7Simulation scopeDescriptive rooms, objects with simulable properties, and scripted behaviours. No utility networks (§4).
Q8Base action time and clock pace1–5 game minutes per action at AP 8, scaled by 8 / AP. Tune in playtesting (§4.8, §5.5).
Q9LLM interpreterNone. Exploration input is now Q19.
Q10Subscription access mechanismClaude Agent SDK, in-process, tools disabled (§6.9). Confirming the terms is now Q30.

Q12PersistenceSQLite, one database per save game (§3.7).

Q18Velocity in dimensionless roomsAn abstract magnitude set by throw/push, decaying per tick and combined with mass on impact. Throws use the Throwing skill (§4.2).
Q19Exploration inputBoth a verb–noun parser and an action menu (§3.2).
Q20Free-text conversation optionNo for v1 (§6.3).
Q21Joining or overhearing conversationsOverhear only. Others in the room get the transcript in their day log but can't take part (§3.3).
Q22First example storyThe Pier: a present-day ghost story on a Victorian pier, with silent apparitions, madness as flags plus SPECIAL modifiers, and a discovery-paced inevitable ending with a deadline (brief, §7.9).
Q23Conversation memoryDay-based. A raw day log during the day, a per-character summary when the player sleeps, and all previous summaries put at the front of later calls (§6.8).
Q24Ranged fire into adjacent roomsNo for v1: same room only (§5.6).
