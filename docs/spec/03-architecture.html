Layers, the turn loop, persistence and testing strategy.

Dependency rule: the simulation core has no dependency on the LLM layer. It is plain, pure, deterministic TypeScript and can be tested with no model at all. The narrative layer depends on both the simulation core and the provider interface. Frontends depend only on the session.

3.2 The turn loop

  1. Input. The player types free text.
  2. Interpret. A classic fast-path parser handles unambiguous commands (n, look, take lamp). Anything else goes to the Interpreter role, which returns a typed Intent from a closed set (move, examine, take, use, say-to, attack, wait…) with entity references resolved against what is in scope. It can also return a clarification question.
  3. Validate. The rules check preconditions: reachability, locks, possession, power and so on. Failure produces a structured reason and no state change.
  4. Resolve. Apply effects as events. Dialogue intents call the Character role for the addressee. That role returns an utterance plus any proposed actions or knowledge transfers, and those are validated in turn.
  5. Advance time. The clock ticks according to the action's cost. Scheduled resident behaviour runs off-stage using rules only. Utility networks propagate.
  6. Direct. Every N ticks or on salient events, the Director may propose a beat. Proposed beats are validated like any other action.
  7. Narrate. The Narrator turns this turn's events and the perceivable scene into prose. It is constrained to entities in scope.
  8. Persist. Append events and recorded LLM exchanges, and snapshot periodically.

3.3 State & persistence

  • Event-sourced. The authoritative record is an append-only event log. The current world is a fold over it, with periodic snapshots.
  • Save file = world seed + snapshot + event tail + LLM exchange log. open JSON files or SQLite.
  • Serialisable everything. World state is plain data with no class instances holding hidden state, so snapshots are structuredClone-able and diffable.

3.4 Determinism

  • All randomness comes from a seeded PRNG carried in state. Math.random and wall-clock time are banned in the core.
  • LLM calls are recorded as (role, request hash, response). Replay mode serves responses from the log. This is the "cassette" pattern, and it makes the non-deterministic part reproducible.
